# WoW: Forever add-ons

Installed release client 1.60.1.70790 (`wowf`, `_forever_`) / Interface 16001. Addons were last updated 2026-11-12 (GearInsight held at 0.7.4); loading on this release still needs an in-game check. Thirty upstream addon folders plus two local addons are installed. MapUtils was added 2026-11-08; GatherLite and Lueur were added 2026-11-09. EllesmereUI owns individual/group frames and nameplates; YUI owns bars, bindings and interface helpers. GearInsight provides talents, loot, gear farming, macros and leveling planning. Details owns combat meters and analysis. Skinner supplies complementary Blizzard-window skins. Waypoint UI owns in-world navigation display. Bagnon owns bag, bank and guild-bank windows. MapUtils adds flight-point status, zone crossings, fishing and zone-level labels, and dungeon maps with boss pins to the world map.

## Feature ownership and overlaps

- YUI retains quest/gossip automation, junk selling, its quest-item action bar, experience display, action bars and bindings.
- EllesmereUI retains individual/group frames, nameplates, health/cast displays and class resources. The guard disables competing YUI health/cast/resource HUDs and nameplate synchronization, plus EUI's duplicate nameplate power display. Swing timers and YUI cooldown tracking remain available.
- GearInsight's combined resource/DoT/cooldown/proc HUD is off while either YUI or EUI Unit Frames owns those displays. Its separate rotation recommendation board remains available.
- GearInsight's floating leveling panel is off while YUI owns the experience display. The main leveling plan, talents, macros and gear recommendations remain available.
- GearInsight automatic friendly-nameplate toggling, now in its load-on-demand Group module, is off while EUI Nameplates loads. The guard restores only a pending toggle recorded by GearInsight; it does not force user-selected friendly visibility.
- GearInsight's bar-placement, slot and spell clearing, key assignment/unbinding/presets, main-bar reset and restore actions are read-only while YUI loads. Its key inspection and macro creation/import remain available. Place imported macros using the normal owner UI.
- GearInsight item translations and Forever change notes supplement tooltip styling. Map destinations, its unique rotation board and user-invoked system macros remain optional; these may change the shared map waypoint or startup CVars when used.
- Details is the only installed combat meter: YUI's Forever loader does not load YDamageMeter, and EllesmereUIDamageMeters is absent. YUI's Details specialization-icon integration remains enabled because it supplements the meter. TinyThreat group rankings supplement EUI's per-unit threat indicators. Details Raid Check and GearInsight talent planning serve different purposes.
- The optional Details_Streamer cast/action overlay and Details_Vanguard tank-health/debuff frames are not installed because existing YUI/EUI displays own those features. Review these exclusions again if installing additional Details plugins.
- Skinner's individual/party/compact frames, castbar and nameplate skins stay off under the corresponding EUI owners. Its action/status bars, minimap/buttons, world map, chat and tooltip skins stay off while YUI loads. Details and DetailsFramework widget skinning stay off while Details loads. Every guarded setting is listed in the [policy table](OverlapSettingsGuard/readme.md); Blizzard-window and Auctionator skins remain available.
- Skinner's EllesmereUI skin is excluded by a local patch to `AddonSkins/_AddonSkins.xml`. Upstream, it moves Skinner to a new profile with `DisableAllNPC`, `DisableAllP` and `DisableAllUI` on, removing the Blizzard-window skins this pack keeps Skinner for, and replaces its skin functions with callbacks delivered only by EllesmereUIBlizzardSkin, which is absent. Skinner has no setting to skip the file, so no guard policy can cover it.
- YUI's `EllesmereUIEnhancement` component restyles EUI windows, but nearly all of that requires the absent EllesmereUIBlizzardSkin, so it does not compete with Skinner here. YUI's resource manager is covered by the existing guard rules; user-created custom resource bars stay available. Its damage-meter reset prompt is opt-in and supplements Details.
- GearInsight's level-up filter hides other players' level-up announcements in chat; since 0.7.x it is off by default (`/gi 屏蔽升级 开` turns it on). GearInsight 0.7.x posts your own level-up to guild chat automatically every fifth level and asks with a pop-up at other levels; the earlier milestone default is migrated to this mode (choose another in its settings). GearInsight 0.5.11 re-enables its guild/officer level prefix and YUI v352 adds a YChat keyword filter for GearInsight and quest-guide announcements; both are chat filters on by default, so the guard keeps both off while YUI and GearInsight load (`gi.guildchatlevel`, `yui.chatkeywordfilter`). GearInsight's level-up filter remains the only filter for those messages. GearInsight 0.5.11 quest-mate sharing, active only after its Group tab loads, sends your zone, coordinates and quest progress to guild chat and to up to six nearby players by hidden addon whispers every 30 seconds; `/gi qm off` stops it. It also records up to 400 gathering-node coordinates in its saved variables. It records training, recipe and gathering data in saved variables for upload by its separate updater, which this pack does not install. GearInsight 0.7.x also, by default: offers a guild-chat pop-up after PvP kills and deaths (nothing is sent until you click Send; building its map link briefly sets and then restores the map waypoint that Waypoint UI displays), adds a zone tag to the guild level prefix (inactive while `gi.guildchatlevel` keeps the prefix off), shows character-panel corner icons, a quest-chain tracker window and an "invite to guild" menu entry, registers a LibDBIcon minimap button, and sets free-for-all loot when you lead a group formed from its Group tab outside instances (`qm.autoFFA`). It always records hunter-pet sightings and tames with NPC ID and map coordinates for its updater. Its optional guild stats report (off by default) also turns on chat logging.
- Waypoint UI replaces Blizzard's in-world navigation frame and sets `showInGameNavigation` on until logout at each load. YUI map markers/event navigation and GearInsight map destinations only choose the super-tracked target, which Waypoint UI then displays; GearInsight's printed `/way` coordinates become usable. EUI's `/way` command belongs to the absent EllesmereUIQoL module. No installed addon registers `/way`, `/waypoint` or `/wp`, and Skinner has no Waypoint UI skin. Waypoint UI 1.7.5 wraps the YUI-owned minimap's `OnMouseUp` for Ctrl-left-click custom pins, which do nothing while `CustomMapPinsEnabled` stays at its default off; YUI's minimap uses right-click `OnMouseDown`, so they do not collide. No guard policy is required. Its default "Game Font" follows the client font (Rurutia).
- LootRollMover places Blizzard's group loot roll stack. On this client Blizzard derives the stack's height from native bottom bars that YUI hides or keeps invisible, and YUI's own loot-roll bridge loads only on retail, so no other installed addon positions it. Its optional alert-toast mover (`alertEnabled`) is off, so toast placement stays with Blizzard. Skinner's loot-frame skin is complementary styling. No guard policy is required.
- Bagnon replaces Blizzard's bag, bank and guild-bank windows. YUI's Blizzard-bag enhancements become inactive while it loads: the combined-bag position (x=0.88, y=0.30), `fixBagSortButton`, and the Profession Assistant entry docked on the Blizzard backpack. With YUI `bagsBarVisibility="auto"`, Blizzard bags never report open, so the Blizzard bag bar stays hidden; Bagnon's own bag-slot toggle replaces it. Set that YUI option to `show` to keep the bar visible. EllesmereUIBags, which EUI auto-disables beside Bagnon, is absent. Bagnon 12.1.9 also hooks Blizzard's combined-backpack toggle to hide that window itself; with `combinedBags` off by the local patch the hook stays idle. YUI's enchanting assistant entry on Bagnon's backpack shows from v355 for characters with Enchanting (v347–v354 accepted only Bagnon 12.1.7); it can be turned off separately. No installed addon adds tooltip item counts. Skinner's Bagnon skin follows its `ContainerFrames` setting as complementary styling. No guard policy is required because the YUI settings are inert rather than competing.
- MapUtils and YUI share the world map. YUI keeps the window position, scale, fade and static dock, zeppelin and tram markers, so the guard keeps those MapUtils settings off (`mu.worldmapmove`, `mu.worldmapscale`, `mu.worldmapfade`, `mu.pierpins`). MapUtils owns flight points, so the guard keeps YUI's flight-point marker off (`yui.flightmarkers`). It owns unexplored-area reveal, because One Map hides the exploration layer YUI draws on, so YUI's reveal stays off (`yui.mapreveal`); the look is set by MapUtils' tint in `/maputils`. It also owns zone-level and fishing labels, so Forever Essentials Zone Levels stays off (`euife.zonelevels`). MapUtils' moving transports, minimap piers, dungeon entrances and meeting stones have no YUI counterpart and stay on. Its One Map setting, on by default, gives the world map stepless zoom and mixes in terrain when zoomed in; YUI has no equivalent, so it is not guarded and can be switched off in `/maputils`. MapUtils 1.5.x keeps its own fader running whenever the client's movement fader exists, even with its fade off, which would hold the map opaque over YUI's fade; a local patch restores the 1.4.25 check so `mu.worldmapfade` works. MapUtils 1.5.x also adds a fullscreen button to the world map that resizes it regardless of YUI's position and scale (it acts only when clicked), and always hides the dark backdrop behind the map. MapUtils 1.6.x adds a cog menu on the map title bar (beside YUI's drag handle), a top-right map-icons bar, a party list and a zone-info box that always replaces Blizzard's map area label. The map-icons bar's Piers button switches `WORLDMAPPINS` back on with one click; `mu.pierpins` turns it off again at the next load. It also rewrites the game's waypoint distance text in metres by default (`/maputils` → yards), which shows only when Waypoint UI hands navigation back to the game, and groups online guild members by zone from the local roster. MapUtils also, by default: shares your map position with your guild (at most every 5 seconds while moving, never in instances), joins a hidden `MapUtils` chat channel and uses guild and group messages to exchange transport timetables, shows available quest givers and turn-ins on the world map, and adds gathering-node icons to the minimap. Its coordinate display follows the native coordinate console settings and YUI keeps its own; no rule is added.
- Auctionator owns auction shopping and searches. YUI v357 loads its Auction Helper on Forever, on by default, which docks a second shopping panel beside the auction house, so the guard keeps it off while Auctionator loads (`yui.auctionhelper`). Its saved shopping lists are kept. YUI v357's optional `!YUI_Error` addon is not installed: it would register as a BugGrabber display and silence BugGrabber's chat notice.
- GatherLite owns known gathering locations and routes, which no other installed addon provides. Its minimap markers show where nodes can spawn, while MapUtils marks nodes currently tracked, so both stay on and may stack when a node is up; turn GatherLite's off in `/gather` if that is too busy. Since 8.4.5 it no longer switches Find Herbs/Find Minerals itself; when no tracking spell is active it shows a clickable reminder beside the minimap until closed or the next reload. Its map reveal and zoom apply only to its own map window, so they do not compete with YUI or MapUtils. GearInsight only records node coordinates and EUI Gathering Skill only adds tooltip text. GatherLite broadcasts its version number, and nothing else, every 10 seconds to guild, group and yell addon channels. About 12 MB of route data loads at login.
- Lueur owns the in-world glow. The guard keeps its minimap herb and ore markers off while MapUtils loads (`lueur.nodeherbs`, `lueur.nodeore`), because both mark the same tracked nodes and each Lueur scan briefly hides the minimap. Lueur keeps soft-target interact on at 15 yards in all directions, which changes what the interact key selects, and hides the game's highlight on anything it does not glow; it restores these CVars on logout. EUI Fishing Key shares `SoftTargetInteractRange` (30 yards; Lueur uses 60 while a line is out). The glow attaches to game-object nameplates, which EUI Nameplates also handles. Its optional far glow, which borrows the waypoint Waypoint UI displays, is off by default. EUI 9.8.4 friendly plates move the game's interact icon onto game-object nameplates; Lueur 1.6.x hides that icon while it glows the object and restores it afterwards, so the two must stay at these versions or newer together.

GearInsight uses the same Chinese strings for zhCN and zhTW, largely Simplified Chinese. The zhTW client remains selected. Client terminology can differ from its bundled Chinese names; name-dependent features require live verification.

## Settings and transfer

Existing YUI/EUI settings, resolution, UI scale, fonts, macros and bindings are preserved. GearInsight account defaults start with `qm.autoPlates=false`, `keysHud=false` and `leveling.shown=false`; the guard enforces ownership again after login, including new characters. Existing character addon lists enable GearInsight. Guide progress, saved talent plans and wishlists from the retired packages are not migrated into GearInsight.

The six selected Details modules are enabled in existing character addon lists. Their first-run window/options setup is left to upstream; no new profile or fixed window position is imposed. Details saved combat databases are not part of anonymous settings capture, but the private adoption script copies them with the rest of live WTF. Existing settings and gameplay UI scale are unchanged at all three target resolutions; verify meter placement and text in-game at each resolution.

Skinner is enabled in existing character addon lists. The guard applies its ownership settings before login skinning and after profile changes, including new accounts; it covers stored profiles and UnitFrames namespace defaults. Skinner settings are not yet included in anonymous snapshots, but adoption copies all live WTF, including future SkinnerDB saved profiles. No resolution, UI scale, map size or viewport is changed. If a skin was already applied before a later option change, follow the guard's chat request to `/reload`.

YUI's official buff icons and tracked buff bars retain their original relative anchors in the active placement stores and saved HUD preset; the direct-center override was reverted. The combined bag window keeps its normalized center at x=0.88, y=0.30, leaving room above the lower-right bag bar while retaining automatic bag-bar visibility. Buff visibility settings and assignments are preserved. Actual bag clearance depends on bag dimensions; check it in-game at the three supported resolutions.

All four existing characters use the reference native UI baseline. CharacterUIBaseline 0.3.0 reapplies the supported baseline on every target login/reload, skipping the configured source character. It no longer selects or imports Edit Mode layouts, which tainted Edit Mode and blocked logout; it reports a differing layout so it can be selected manually. Edit `Settings/character-ui-source.local.json` to change its account/character. Source logout publishes current UI values for same-account character switching; the existing post-exit watcher refreshes generated files for subsequent client starts and other accounts. EUI/YUI shared settings remain in place; Details retains its shared reference profile. Spec/talent selections, spec-to-profile assignments, macros, bindings, subscriptions, tracking and combat history are excluded. See the addon readme for exact scope and refresh commands.

The three replaced packages and their `.lua`/`.lua.bak` saved settings were removed from active AddOns/WTF. Obsolete guard integration and active settings snapshots were removed. Private recovery copies live outside Interface under `_classic_beta_/addon-backups/gearinsight-20261015-102755`. Historical changelogs are retained.

`Settings/WTF` captures anonymous, reusable account-level EUI/YUI/GearInsight configuration. Character records, progression, profile-to-character assignments and runtime caches are excluded; restore preserves their current live values. Live WTF and the private alias map remain outside Git. See [settings documentation](../Settings/readme.md).

Run the adoption script from the source game root with WoW closed on both installations:

```powershell
.\Interface\adopt_addons.ps1 \\destination\WoW\_classic_beta_ -Resolution 1920x1080
```

The positional destination must already exist and be writable; `-Destination <path>` is equivalent. The script replaces destination Interface/WTF after backup and merges Fonts, preserving destination-only font files. It rolls back failed replacements. `-Resolution` supports 1920x1080, 2560x1440 and 3840x2160; EUI options scales are 0.90 / 1.00 / 1.50 respectively. Without it, settings are preserved. Account folder differences require manual saved-variable transfer. The script checks local processes and cannot confirm the remote game's state. No source-code change was needed to carry the migrated pack.

## Portable fonts

YUI's seven bundled fonts have byte-identical copies under game-root Fonts: `YUIInterBlack.ttf`, `YUIInterBold.ttf`, `YUIText.ttf`, `YUILongZhu.ttf`, `YUIHOOGE.ttf`, `YUIDamage1.ttf` and `YUIDark.ttf`. Two YUI source files use those paths while retaining font-selection names. EllesmereUI's saved `fctFont` selects the LongZhu copy; EUI owns damage text. Font sizes/layouts are unchanged. Updates overwrite the YUI references; retain the copies and run `uv run --no-project python tools/apply_addon_patches.py` after each YUI or Skinner update. It fails without writing if upstream changed the expected text. Adoption copies and backs up Fonts. Fully exit/restart to discover new assets.

## Default game font

Rurutia (Montserrat + Source Han Sans SC ExtraBold, from SharedMedia_Rurutia v2.2.9) replaces the client's standard, header, unit-name and chat font files in game-root Fonts: `FRIZQT__.TTF`, `FRIZQT___CYR.TTF`, `ARIALN.TTF`, `MORPHEUS.ttf`, `MORPHEUS_CYR.TTF`, `ARHei.ttf`, `ARKai_T.ttf`, `arheiuhk_bd.ttf`, `bHEI00M.ttf`, `bHEI01B.ttf` and `bLEI00D.ttf`. It covers Big5 (zhTW) and GBK (zhCN) except one unused bopomofo tone mark; Traditional text uses Simplified-standard glyph shapes. The damage-text files `skurri.ttf`, `SKURRI_CYR.TTF`, `ARKai_C.ttf` and `bKAI00M.ttf` are unchanged. Add-ons on default/system fonts follow it; explicit picks such as YUI's bundled faces do not. These copies are not tracked by Git; adoption carries them with Fonts.

YUI's full YUnitFrames product is not loaded by its Forever loader, and it has no party/raid replacement in this pack. Keep EUI for those frames. YUI's Platynator installer step remains unused. Old standalone EUI folders remain absent.

## Verification and limits

The migration checks guard behavior, current package/dependency integrity, saved-setting cleanup and preservation, fresh class/faction profiles, font assets, anonymous settings capture and adoption at all three target resolutions. These checks do not simulate game rendering. The subsequent 2026-10-15 10:38-10:53 session captured no new BugGrabber errors and retained GearInsight's guarded settings. AsyncFile.log still reported one YUIInterBlack.ttf manifest-load failure and two missing texture ID 137237 failures; the texture's caller is not identified. The four older BugGrabber reports were unchanged. Glyphs, tooltips, secret-value handling and appearance at 1080p/1440p/4K remain incompletely verified.
