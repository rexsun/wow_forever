# PlayerCastBar

Anchors below PrimaryResources. Enables talent tracking. Suppresses native `PlayerCastingBarFrame` via a one-time `OnShow` hook: `Hide()` normally, but `SetAlpha(0)` when the frame is `IsProtected()` — some EditMode layouts anchor a protected frame (e.g. the target frame) onto the cast bar, making `Hide()`/`HideBase()` blocked in combat. A `SetAlpha` hook re-pins alpha to 0 when Blizzard raises it; `OnDisable` restores alpha to 1. Font: `castbar_font_profile` with independent cast name/time settings, each with configurable anchor point and offsets.

- `show_when_casting` (default false): forces the cast bar visible during casting/channeling via `GetForceVisible`, bypassing anchor chain hide decisions while preserving inherited alpha/fade.
- `show_latency` (default false) / `latency_color`: a coloured region covering the last *latency* seconds of the bar — the window in which the next cast can already be queued.
  - **Measurement.** Identical to the GCD bar's: the delta between `CURRENT_SPELL_CAST_CHANGED` and `UNIT_SPELLCAST_SENT`, replaced by `GetNetStats()` world ping when that delta falls outside 0.05–0.6 s. Like the reference, re-measured at each event where *this* bar starts — a hard cast at `UNIT_SPELLCAST_SENT`, a channel or empower at `OnCastStart` (checking `bar.channeling`, which DF sets for both). The re-measurement lives in the `OnCastStart` hook rather than on the event itself so it is deterministic: same frame, same hook, immediately before the value is consumed, with no dependency on dispatch order between the addon's event frame and DF's cast bar frame. Deliberately *not* re-measured on `UNIT_SPELLCAST_EMPOWER_STOP`, which the GCD bar does measure at: that is when the *GCD* starts, not when this bar starts, so measuring there would overwrite the value after the overlay had already been drawn. Also deliberately *not* invalidated on `ACTIONBAR_UPDATE_STATE`/`SPELL_UPDATE_COOLDOWN` the way the reference invalidates `castStarted` — registering `SPELL_UPDATE_COOLDOWN` here would add a high-frequency event handler to a combat path for a marginal gain (see `.context/performance.md`). Consequence: when the delta is implausible, both bars fall back to the same `GetNetStats` ping, so they still agree; they can differ only when one bar falls back and the other does not.
  - **Bar duration.** Derived from the DF bar's own millisecond timestamps, `(maxValue - minValue) / 1000` — **not** from `durationObject:GetTotalDuration()`. On a regular cast that duration object can still come from `UnitCastingDuration` (CastBar's shim swaps in a plain cast-info span only when that info is readable, #50), which is flagged `SecretReturns`, and comparing or dividing by a secret throws; a throw inside a DF widget hook aborts the rest of the hook list, which would take the cast-state transition with it. `minValue`/`maxValue` originate from `UnitCastingInfo`/`UnitChannelInfo` (secret only while unit spell casts are restricted), so both are `issecretvalue`-guarded and the overlay simply hides when either comes back secret.
  - **Staying current.** Those timestamps are re-assigned on `UNIT_SPELLCAST_DELAYED` (pushback), `UNIT_SPELLCAST_CHANNEL_UPDATE` (clipped or re-entered channel), and `UNIT_SPELLCAST_EMPOWER_UPDATE` (delegated by DF to `CHANNEL_UPDATE`) without a fresh `OnCastStart`, so a second `OnEvent` hook re-derives the overlay for those three events. `Refresh` re-derives it too, gated on the component's `isCasting` state: toggling the option or changing orientation applies mid-cast, and nothing is drawn outside a cast. Entering Edit Mode does not clear `isCasting`, so a cast still in progress when Edit Mode opens keeps its overlay drawn alongside the dummy preview.
  - **Appearance.** Wears the bar's own LibSharedMedia statusbar texture tinted with `latency_color`, falling back to solid white when the key is empty or unregistered — the same treatment the GCD bar gives its latency region. Sits at the end the bar travels toward: the far edge for a cast or empower (ElapsedTime fill), the start edge for a draining channel (RemainingTime). Drawn at artwork sublevel 1, above the fill and below the icon and spark. No Edit Mode preview (matches the GCD bar).
- `pushback_flash` (default true; "Pushback Cutaway" — the key keeps the name of the flash it replaced): when a cast is pushed back or a channel cut short, the progress lost stays on the bar as a red block that holds, then fades. Not for empowers. Player only — target/focus carry no such key. Read live per bind, so no refresh and no `private.fontsDirty`. Pushback from damage is a classic-era mechanic, so on modern content it rarely shows; there is no client gate. The *timing* half does not depend on this setting: the bar's fill is bound from `UnitCastingInfo`/`UnitChannelInfo` whenever that info is readable, so it follows a pushback (#50). See [CastBar.md](CastBar.md) — **Spell pushback**.
- `track_instant_casts` (default true): briefly repurposes the cast bar to show the GCD as a backward-draining bar (labelled with the spell name and icon) after instant-cast spells; uses the `castbar_colors.instant_cast` color.

Defaults: 200×20, enabled.
